# 校园食堂线上订餐与错峰取餐系统项目介绍

## 项目定位

本项目是《Web 程序设计》课程考核项目六的完整实现，面向校园食堂场景，提供线上浏览菜品、加入购物车、下单支付、预约取餐时段、商家核验取餐码和管理员统计导出等能力。系统采用前后端分离架构，前端为 Vue 3，后端为 Spring Boot 与 MyBatis。

工程位置：`E:\javawebxs`

公开仓库：https://github.com/dyychen/javawebxs

## 要解决的问题

传统食堂在午餐和晚餐高峰存在三个突出问题：窗口前排队时间长，学生不知道实时菜品和库存，商家也难以及时确认订单是否完成。项目六希望把点餐环节前置到线上海选，把现场环节压缩到“凭码取餐”，从而减少拥挤和等待。

## 用户与职责

| 角色 | 典型操作 |
| --- | --- |
| 学生 | 浏览菜品、筛选窗口、加购、下单、模拟支付、查看取餐码 |
| 商家 | 管理本窗口菜品和库存、查看订单、核验取餐码 |
| 管理员 | 查看营业概览、管理窗口和分类、查看用户和订单、导出 CSV |

## 系统规模

初始数据覆盖 3 个校区、6 个窗口、6 个分类、24 个菜品和 10 个用户。三类演示账号分别是 `student1/123456`、`merchant1/123456`、`admin/admin123`。

## 功能全景

1. 多角色登录与会话保持。
2. 食堂窗口、分类和菜品管理。
3. 菜品浏览、关键字搜索、按校区和分类筛选。
4. 购物车数量修改与清空。
5. 按窗口拆分订单并模拟支付。
6. 取消未支付订单并回补库存。
7. 学生查看订单和取餐码，商家核验取餐码。
8. 管理员查看销量排行、订单统计并导出 CSV。

## 技术架构

后端分为 Controller、Service、Mapper 三层。Controller 负责接收请求和组织统一响应；Service 承载业务规则与事务；Mapper 使用 XML 编写 SQL。会话基于 `HttpSession`，权限按学生、商家、管理员三种角色划分。前端不使用路由库，而是根据角色切换主视图。

## 使用方式

本地开发时，在仓库根目录运行 `npm.cmd run dev` 启动前端，访问 `http://localhost:5175`。后端启动类是 `com.example.canteen.CanteenApplication`，默认端口为 `8080`。生产模式先执行前端构建，再由 `java -jar target/canteen.jar` 统一托管。

## 项目价值

该系统把课堂中的 Spring MVC、MyBatis 动态 SQL、事务、会话与 Vue 组件化串联成完整业务。它既能作为课程考核作品，也能作为后续继续扩展校园生活服务的起点。
